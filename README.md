# depviz

CLI-инструмент для построения и визуализации графа зависимостей
пакетов Python (pip). Менеджеры пакетов и сторонние библиотеки
для получения зависимостей **не используются**.

## Возможности

- Получение прямых зависимостей пакета через PyPI JSON API.
- Построение графа зависимостей алгоритмом DFS с рекурсией.
- Ограничение максимальной глубины и обработка циклов.
- Вывод обратных зависимостей.
- Визуализация: Mermaid-диаграмма и ASCII-дерево.
- Режим тестирования на локальном файле описания репозитория.


### Параметры

 Параметр        Описание
 
`--package`     Имя анализируемого пакета.
`--repo-url`    URL репозитория или путь к тестовому файлу.
`--mode`        `real` (PyPI) или `test` (локальный файл).
`--max-depth`   Максимальная глубина анализа (1..100).
`--ascii-tree`  Вывести зависимости в виде ASCII-дерева.
`--reverse`     Показать обратные зависимости.
`--mermaid`     Вывести граф в формате Mermaid.

## Формат тестового репозитория

    A: B, C
    B: D
    C: D, E
    D:
    E: A



## Этапы разработки

1. **Этап 1** — CLI, конфигурация, обработка ошибок.
2. **Этап 2** — получение прямых зависимостей с PyPI.
3. **Этап 3** — граф зависимостей (DFS, глубина, циклы).
4. **Этап 4** — обратные зависимости.
5. **Этап 5** — визуализация (Mermaid, ASCII-дерево).
