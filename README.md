# depviz

CLI-инструмент для построения и визуализации графа зависимостей пакетов
Python (pip). Зависимости загружаются через JSON API без менеджеров пакетов
и сторонних библиотек. Для запуска нужен Python 3.9 или новее.

## Запуск

Локальный пример с циклическими зависимостями:

```sh
python -m src.main --package A --repo-url examples/sample_repo.txt --mode test --ascii-tree --mermaid
```

Получение зависимостей с PyPI:

```sh
python -m src.main --package requests --repo-url https://pypi.org/pypi --max-depth 2 --ascii-tree
```

В Linux/macOS можно также запускать `bash run.sh` с теми же аргументами.

## Параметры

| Параметр | Описание |
| --- | --- |
| `--package` | Имя анализируемого пакета. Обязательный параметр. |
| `--repo-url` | Базовый URL JSON API или путь к тестовому файлу. Обязательный параметр. |
| `--mode` | `real` (по умолчанию, PyPI) или `test` (локальный файл). |
| `--max-depth` | Максимальная глубина анализа от 1 до 100, по умолчанию 5. Корень имеет глубину 0. |
| `--ascii-tree` | Вывести зависимости в виде дерева. |
| `--reverse` | Показать, какие пакеты зависят от каждого пакета. |
| `--mermaid` | Вывести граф в формате Mermaid. |

В режиме `real` URL используется для запросов вида
`<repo-url>/<package>/json`. Для URL без пути автоматически добавляется `/pypi`.
Произвольный сервер должен поддерживать формат PyPI JSON API.

Граф строится рекурсивным DFS. При глубине 1 выводятся только прямые
зависимости; граничные узлы не загружаются. Циклы отмечаются `(cycle)`.
Повторно встречающийся пакет раскрывается с учётом глубины и текущего пути.

В режиме `test` обратные зависимости вычисляются по всему локальному файлу,
включая пакеты, недостижимые из выбранного корня. В режиме `real` они
вычисляются только по графу, загруженному от корня до `--max-depth`:
PyPI JSON API не предоставляет глобальный список обратных зависимостей.

## Формат тестового репозитория

Имена пакетов состоят из заглавных латинских букв. Пустые строки и строки
с `#` в начале игнорируются.

```text
A: B, C
B: D
C: D, E
D:
E: A
```

## Проверка

```sh
python -m pip install -r requirements.txt
python -m compileall -q src tests
python -m pytest tests -v
```

Также доступны `make install`, `make lint` и `make test` при наличии Make.

## Сообщения коммитов

Используйте Conventional Commits с областью изменения:

```text
fix(graph): respect maximum dependency depth
test(cli): cover command-line execution
docs(readme): document installation and usage
```

Для соответствия C6 сообщения старых коммитов приведены к этому формату.
При переименовании коммитов изменяются их SHA; содержимое исторических
снимков, авторство и даты сохраняются.

## Этапы разработки

1. CLI, конфигурация, обработка ошибок.
2. Получение прямых зависимостей с PyPI.
3. Граф зависимостей: DFS, глубина, циклы.
4. Обратные зависимости.
5. Визуализация: Mermaid и дерево.
